Action & Stuff Not Working? Common Problems and Fixes

Failed to import, pack not showing, textures not loading, animations frozen: when the pack misbehaves, the cause is almost always one of the four problems below. Work through them in order before you reinstall anything. Each fix takes under a minute.

Pack Not Showing or Not Active

Open Settings, then Global Resources, and look for the pack. If it is under Available Packs instead of Active Packs, the pack is imported but not turned on. Activate it there. If it is missing from both lists, the import failed, so download the file again and import it once more.

Missing Textures

Purple and black squares or missing textures mean the pack file is damaged or the game version is too old for it. Update Minecraft to a recent version, download the current release of the pack again, and import the fresh file. Do not stack an old build under a new one.

Animation Conflicts

Frozen or broken animations usually mean two animation packs are fighting over the same files. Ordinary texture packs are compatible with this pack and run alongside it without trouble. Animation packs cannot stack: two packs cannot rewrite the same animation files, so keep only one active.

FPS Drops and Lag

Drops after installing almost always trace back to a resolution subpack that is too heavy for the device. Move down one level, from 64x to 32x or from 32x to 16x, and the animations stay identical while the load falls. The performance tips below finish the job.

Performance Tips for Smooth Gameplay

Keep the game updated, because the studio tunes each release for the current version. Lower your render distance a few chunks if busy areas lag or stutter. Close heavy background apps before a long session. And if a world still struggles, drop one subpack level: the movement you came for is identical at every level.
