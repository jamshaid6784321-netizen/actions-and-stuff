How to Install an Old Version

Installing an action and stuff old version follows the same process as installing the latest release, with one extra step at the start: deactivate the version you already have before you import the older file. The key step is that deactivation, and it applies on every route below. If you prefer to watch, a video tutorial on YouTube walks through the same steps, and the written steps below match it. On console, Xbox and PlayStation players (PS4 and PS5), controller in hand, and Nintendo Switch players too, get the pack through the in-game Marketplace instead of a file, so the MCPACK route below is for mobile and PC. Pick your route, follow its steps in order: the installation takes a few minutes and the pack will be live and running.

Install an Old MCPACK on Android, iOS and PC

  1. Download the MCPACK file for your chosen version from the download button in its section above.
  2. Open Minecraft, go to Settings, then Global Resources, and deactivate the Action and Stuff version you have active now.
  3. Tap the downloaded MCPACK file on your phone, whether Android or iPhone, or double click it on Windows. A MCPACK file is a renamed zip file, and Minecraft opens by itself and imports the pack, which works like any Bedrock addon or mcaddon file. On PC, keyboard and mouse (KBM) work exactly as before.
  4. Go back to Global Resources, find the imported version, and tap Activate. It sits beside your other addons in Global Resources.
  5. Load any survival world and watch the animations. If the mobs move and your character swings properly, the install worked.

You can keep multiple versions installed on your device, but activate only one at a time, because two animation packs active together will fight each other.

Install an Old APK on Android

  1. Download the APK file for your chosen version from its section above.
  2. Back up your Minecraft worlds first, because switching APK versions can leave newer worlds unreadable.
  3. Uninstall the Minecraft version you have now if the APK asks for a clean install.
  4. Open your Downloads folder, tap the APK file, and allow installs from your browser or file manager for this one install.
  5. Wait for the install to finish, then open the game and check the version on the main menu.

The APK route installs a whole Minecraft build with the pack inside it, so it suits players whose game itself needs to go back a version, not just the pack.

Common Problems With Old Versions

Most problems with an action and stuff old version come down to one thing: the file and the game do not match. The four fixes below cover nearly every case players meet.

The Pack Does Not Work

The most common cause is installing a version that does not match your Minecraft Bedrock version. Check your game version on the main menu, then check the compatibility chart at the top of this page and download the file that supports it. A v1.9 file on Minecraft 1.16, or a v1.6 file on Minecraft 1.21, will not load properly, and no reinstall fixes a mismatch.

Animations Are Missing

Check Settings, then Global Resources, and confirm that the version you installed is actually active. The pack only animates when it is switched on, and an import alone does not activate it. Restart Minecraft after activation if the animations still do not show, and make sure no other animation pack is active at the same time.

The Game Runs Slow

Older devices run better with earlier releases such as v1.8 or v1.9, and lowering the pack's texture resolution also helps: switch from 64x to 32x, or from 32x to 16x, in the pack settings. On a 64-bit phone, the 16x resolution runs smoothly even on the oldest devices here. Close other apps before you play, and keep render distance modest on a weak phone. If the game still lags, the animations are rarely the cause, and a smaller resolution is the first fix to try.

Minecraft Updated and the Pack Stopped Working

If Minecraft gets an update to a newer version, your older resource pack may stop working correctly, because the game and the pack no longer match. In that case, come back to this page, check the compatibility chart, and download the newest release that supports your updated game. Version 2.0 covers Minecraft 1.20.0 to 1.21.x, so it is the file most updated players need.
